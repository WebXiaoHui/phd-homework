# 任务一 · 操作流程

> 本文件记录「熟悉 Transformer」任务的**完整操作流程**：怎么搭环境、写哪些文件、按什么顺序跑、怎么验收。仓库根 `操作日志.md` 记录全局操作。
>
> 目标（一句话）：用约 300 行 PyTorch 从零写一个 Transformer encoder，在 ChnSentiCorp 中文情感二分类上做到 dev 准确率 ≥ 0.80（参考基线 ~0.85），并用注意力热图说清模型在看什么。

**接口对齐表**（决定能否被自检正确评分，改接口需同步改 `eval/run.py`）：

| 文件 | 必须导出 | 自检怎么用 |
|---|---|---|
| `src/attention.py` | `scaled_dot_product_attention(Q,K,V,mask=None)`，Q/K/V 形状 `(B,H,T,D)`；mask bool，`True`=屏蔽，可广播到 `(B,H,T,T)` | 与 `F.scaled_dot_product_attention` 比误差 <1e-5 |

## 3. 写实现（本仓库已写好，src/ 下）

按 README「实现约定」逐层实现，代码位置：

1. **`src/attention.py`** — 手写 `scaled_dot_product_attention` 与 `MultiHeadAttention`
2. **`src/block.py`** — `TransformerBlock` = attention + FFN + 两层 residual + 两层 LayerNorm（**Pre-LN**）
3. **`src/tokenizer.py`** — 字符级分词：`<pad>`=0、`<unk>`=1，输出定长 id 序列
4. **`src/model.py`** — `TransformerClassifier`：词/位置嵌入 → N 层 block → masked-mean pooling → 分类头；外加 `load_for_eval`

手写要点（review 检查项）：
- 缩放因子是 `1/sqrt(d_k)`（d_k = 每头维度），**不是** `sqrt(d_model)`
- 被屏蔽位置 softmax **前**填 `-inf`（不是乘 0，否则概率泄漏）
- multi-head reshape 顺序 `(B,T,D)->(B,T,H,d_k)->(B,H,T,d_k)`，拼回去前 `.contiguous()`
- Q/K/V 用三个独立投影
- padding mask 屏蔽的是「key 是 pad 的列」，形状 `(B,1,1,T)` 广播到 `(B,H,T,T)`

> 说明：写好的代码先跑一遍只有单元测试的前两关，快速验证，不必等训练。

## 4. 运行流程（建议按序）

### 4.1 先跑单元测试（不依赖 checkpoint）

```bash
python eval/run.py
```

预期此时：

```
[通过] attention_correctness: ...
[通过] causal_mask: ...
[跳过] classifier_accuracy: ckpt/best.pt 不存在，先完成训练步骤
```

前两关绿 = attention 数学正确 + causal 不泄漏，即 DoD M1/M4 的核心验证。随后进入训练。

### 4.2 训练分类器

```bash
python train.py                    # 默认超参
```

默认超参起点（README 建议值，训练后可自行消融）：`d_model=128, n_heads=4, n_layers=4, d_ff=512, lr=3e-4, batch=64, epochs=8, max_len=200`。

预期每轮打印 loss / dev_acc，最后：

```
[done] best dev acc = 0.86xx -> ckpt/best.pt
```

- 目标 dev acc ≥ 0.80（**通过线**），参考基线 ~0.85。
- 若长期 < 0.80：加大 `--epochs` / `--lr 5e-4`，或把 `d_model` 提到 192/256；再不行看 4.4 排查表。
- 想看训练曲线：`python train.py --save-curve figures/train_curve.png`

> 首次训练建议显存/内存不大时先在 CPU 用小配置试通 1 个 epoch：
> `python train.py --epochs 1 --n-layers 2 --d-model 64 --batch-size 32`

### 4.3 causal mask 演示（DoD M4）

```bash
python causal_demo.py              # 快速验证：篡改未来 V，过去输出不变
python causal_demo.py --train-toy   # 可选：跑一个小 toy LM 并生成文本（为任务二预热）
```

`check_no_leak()` 与该任务 `eval/run.py` 的 `causal_mask` 测试是同一性质检查。

### 4.4 注意力热图（DoD M5，硬性交付）

需要先有 `ckpt/best.pt`：

```bash
python visualize_attention.py                 # 默认：validation 集 正面/负面/最长句 各一
python visualize_attention.py --head 0        # 指定看第 0 个头
python visualize_attention.py --layer 1       # 指定看第 1 层
```

产出 `figures/attn_positive_layer0_mean-heads.png` 等 ≥3 张热图。
每张图 x/y 轴标字符（query / key），颜色 = 注意力概率。

**看图问自己（写报告用）**：正面样本上「不错/赞/好看」这类词是否被高亮？负面样本上「差/失望/垃圾」呢？模型是不是"看对了关键词"？

### 4.5 最终自检

```bash
python eval/run.py
```

预期三项全绿：

```
[通过] attention_correctness: ...
[通过] causal_mask: ...
[通过] classifier_accuracy: accuracy=0.8xxx ...   (>= 0.80 才算过)
结果写入 eval/result.json
```

三态含义：**[通过]** 契约满足 / **[跳过]** 前置未就绪（缺数据或缺 ckpt，补齐重跑即可，不是错） / **[失败]** 实现与预期不符。

> ⚠️ 必须在仓库内运行 `python eval/run.py`：它依赖仓库根 `_eval_harness.py`。把任务目录拷出去会 import 失败。

## 5. 加分项实验（可选，S1–S4）

| 加分 | 实验 | 做法 |
|---|---|---|
| S1 | head / 层数消融 | 跑 ≥3 组（如 `--n-layers 1/2/4`、`--n-heads 1/2/4`），记录 dev acc 成表 |
| S2 | 拆 residual / LayerNorm | 在 `src/block.py` 里临时注释掉 residual（改 `x = self.attn(...)`）或 LayerNorm，看 loss 是否还收敛 |
| S3 | dev acc > 0.88 | 调大 `d_model`/`epochs`/加 warmup 等 |
| S4 | RoPE 对比绝对位置 | 自行在 model 里把 `pos_emb` 换成旋转位置编码，对比长序列外推 |

每轮实验后写表格：`配置 | dev acc | 观察`。

## 6. 常见问题排查

| 现象 | 原因 / 处理 |
|---|---|
| 自检报 import 错 | 没在任务目录内运行，或 `src/` 下缺文件；检查接口名与上表一致 |
| `scaled_dot_product_attention` 对不上官方 | 检查缩放因子、softmax 维度、mask 是否 `-inf` 而非乘 0 |
| `view` / `reshape` 报错 | multi-head 拼回前漏 `.contiguous()` |
| 训练 loss 不降 / 震荡 | lr 太大、无 warmup、batch 太小；先缩小模型跑通再调参 |
| dev acc 一直 <0.80 | 检查 padding mask 是否真的传进每层 block（漏了 PAD 参与 attention）；加大 `max_len` |
| 热图中文显示方块 | 系统缺中文字体，装 Noto Sans CJK / 文泉驿，脚本会优先尝试匹配 |
| 下载慢/失败 | `export HF_ENDPOINT=https://hf-mirror.com` 后重跑 |
