## 3. 设计决策备忘（任务一代码怎么写的、为什么）

1. **分词用字符级**：中文情感分类不需要预训练词表，自包含、省下载；`load_for_eval` 只读 ckpt 就能重建 tokenizer（vocab 存在 ckpt dict 里）。
2. **定长 + masked mean pooling**：tokenizer 输出固定 `max_len`（默认 200）右侧补 pad；分类 head 前的 pooling 只看非 pad 词元，避免 PAD 污染（对应"mean 时排除 padding"的坑）。
3. **Pre-LN**：现代 decoder 主流结构，residual 在子层外，写作时显式一致；FFN = Linear→GELU→Dropout→Linear→Dropout，中间 `4*d_model`。
4. **mask 统一语义**：`True=被屏蔽` 一条约定贯穿 padding（`(B,1,1,T)` 屏蔽 pad 列）与 causal（`(T,T)` 上三角）——这正好与 torch SDPA 及自检的 mask 语义一致。
5. **自检契约**：`scaled_dot_product_attention` 返回单张量；注意力权重通过 `MultiHeadAttention.last_attn_weights` 额外记录，避免破坏接口。
6. **训练工程**：AdamW + 线性 warmup + cosine 退火 + 梯度裁剪 + 按 dev acc 存 best，符合 tutor 加分项。

### 5.4 关键设计决策

1. **字节级 BPE**：中文天然覆盖（任意 Unicode），roundtrip 有数学保证——merge 只是
   把相邻字节拼成 token，任何合法切分 decode 都能还原字节串。
2. **RoPE half-split**：与 LLaMA 约定一致；频率动态生成、不设上限表，长序列不会 shape 报错。
3. **KV cache = 每层一份 (k,v) 列表**：模型 forward 接收长度 n_layer 的 cache 列表，
   返回拼接后的新 cache；generate 用整 prompt 预热 cache 后逐 token 增量。
4. **weight tying** + GPT-2 风格残差缩放，作为工程加分点。

- 全部 py 文件已通过 `python -m py_compile` **语法级**检查；pycache 已清理。
- torch/transformers 在你环境装好后才能真跑，**未做运行级验证**。两处最容易在首次运行时
  暴露问题：MOSS/DPO 数据 schema 与解析器覆盖是否一致（先 `--inspect`）；`build_labels`
  的子序列定位在真实 tokenizer 上是否与自检 ids 对上。
- 设计上已尽量给「看不见的错」留自检：SFT/DPO 训练前要求解析到样本否则直接报错；

### 6.4 关键设计决策

1. **LoRA A/B 形状**：A `(in, r)`、B `(out, r)`，`delta = (x@A)@Bᵀ·(alpha/r)`——与 `y = Wx + scaling·B(Ax)`
   数值等价；B 全零保证训练初始前向等于原权重。
2. **冻结策略**：`inject_lora` 先把全部参数 `requires_grad=False` 再单独放行 `lora_A/lora_B`，
   embedding/lm_head 一并冻结 → 自检占比远低于 5%。
3. **loss masking 定位法**：不重算 offset，而是对每个 assistant 内容单独 encode 后在整段 ids 上做
   **连续子序列匹配**（Qwen 为 GPT2 风格 BPE，空白与 `<|im_start|>` 等特殊 token 不跨段 merge，
   保证内容 token 是整段 ids 的连续子序列）。顺带把收尾 `<|im_end|>` 也设为监督目标并让 cursor 跳过。
4. **DPO 聚合用 sum-of-logp**（论文口径）；每对 chosen/rejected 共享 prompt 前缀，分开 token 化再
   各算 response logp。若用户遇到 margin 不涨且长度差大的情况，文档里提示可换 per-token 均值变体。
5. **adapter 产物结构** = `adapter_config.json`（target_modules/r/alpha/meta）+ `adapter.bin`
   （只含 `*.lora_A / *.lora_B`），与 README「LoRA 权重目录」的定义一致，也便于 `load_adapter` 复用。

### 7.4 关键设计决策

1. **知识库只用 `data/kb.pdf`**（不是 LaTeX 源）；抽文本后把行间换行合成空格、清掉孤立页码行，
   gold anchor 判定在**去除所有空白后**的子串匹配，等价容忍页缝处的断行。
2. **句子意识 + overlap 切块**：每次在窗口内 `[chunk_size//2, chunk_size]` 找最后一句末标点，找不到
   也在窗口尾切 → 单块长度恒 ≤ chunk_size·1.2，同时 overlap 保住跨缝 anchor。
3. **BGE query 前缀 + L2 归一化 + FAISS IP**：三者缺一召回即坏；统一在 embed 层完成，调用方不感知。
4. **召回 k(20) ≫ 精排 k(5)**：先宽召回再 rerank，检索与精排两段分开可量化（报告口径与 eval 一致）。
5. **生成与检索解耦报错**：没起 LLM 时 `answer` 明确抛错并给出两种起服务方式；`RAG_OFFLINE=1`
   让纯检索管道的 demo 不必依赖生成模型。end-to-end 的忠实性按「要点是否被返回 sources 支持」
   人工抽查，避免用流畅答案掩盖召回失败。
