# Skill: code-review

触发：issue/task 提到 review、审查、有没有 bug、代码质量。

## 流程

1. `read_file` 把目标文件完整读进来；必要时 `grep_search` 看相关调用点。
2. 按三条线过：
   - **正确性**：算术符号/边界条件/空输入/异常路径（对照测试与 docstring 的约定）；
   - **可读性**：命名、魔法数字、重复逻辑；
   - **测试覆盖**：缺什么用例、现有断言能否兜住回归。
3. 每条意见给「问题 + 为什么 + 建议改法（可给 edit_file 的 old/new 片段）」。
4. 不越界：只 review，是否落盘改代码取决于任务要求。

## 输出格式

```
## 结论
总体可用 / 需修复
## 问题清单
1. [严重] 描述 —— 证据：文件:行 —— 建议
...
```
