# 任务二 · 操作流程

> 本文件记录「从零实现 mini-GPT」任务的**完整操作流程**。仓库根 `操作日志.md` 记录全局操作。
>
> 目标（一句话）：用 PyTorch 从零搭 decoder-only mini-GPT——手写 BPE 分词、集成 **RoPE**、实现 **KV cache**，在中文小语料上预训练到困惑度达标并能自回归生成。

**接口对齐表**（自检导入方式）：

| 文件 | 必须导出 | 自检怎么用 |
|---|---|---|
| `src/tokenizer.py` | `BPETokenizer`：`encode(text)->List[int]`、`decode(ids)->str`、`vocab_size`、`from_pretrained(path)` | 中文回环：encode→decode 须还原文本 |
| `src/model.py` | `MiniGPT`：`forward(ids, kv_cache=None, return_cache=False)`、`generate(prompt_ids, max_new_tokens, top_k, top_p, temperature)`、属性 `block_size`；`load_for_eval(ckpt)->(model, tokenizer)` | 开/关 KV cache 的 logits 误差 <1e-4；dev 困惑度低于阈值 |
| `ckpt/tokenizer.json` | BPE 词表 | 存在才跑 roundtrip |
| `ckpt/best.pt` | state_dict + config | 存在才跑后两项 |

自检阈值从 `data/dataset_info.json` 读：**唐诗 < 50**、TinyStories < 10。

## 2. 运行流程（按序）

### 2.1 训练（BPE + 预训练一体）

```bash
python train.py                     # 默认超参
```

train.py 内部依次做：

1. 用 `train.txt` 训练 **字节级 BPE**（`BPETokenizer.train`），存 `ckpt/tokenizer.json`；
2. 先把 tokenizer 做一遍 roundtrip 自检（不通过直接报错，尽早暴露）；
3. 切 `block_size+1` 的滑动窗口，做 next-token prediction；
4. 每个 epoch 用 `dev.txt` 按与自检一致的算法估困惑度，**按最低 dev ppl 存 best.pt**。

建议超参起点（可自行消融）：

| 配置 | 默认 | 说明 |
|---|---|---|
| `--vocab-size` | 1024 | = 256 字节 + merges |
| `--n-embd / --n-head / --n-layer` | 256 / 4 / 4 | 头维 = 256/4=64（RoPE 需偶数） |
| `--block-size` | 128 | 训练与推理的上下文长度，务必一致 |
| `--epochs / --lr` | 20 / 3e-4 | 唐诗小语料易过拟合，看 dev ppl 拐点早停 |

- 预期：唐诗档 loss 稳定下降、dev ppl 掉到 < 50 即可通过（往往几十个 epoch 内）。
- 提示：想先跑通 pipeline 可 `--n-embd 128 --n-layer 2 --epochs 5`。

### 2.2 自检

```bash
python eval/run.py
```

| 测试 | 通过标准 | 对应 DoD |
|---|---|---|
| `tokenizer_roundtrip` | encode→decode 还原中文 / 英文 | M1 |
| `kv_cache_equivalence` | 开/关 KV cache 的 logits 差异 < 1e-4 | M3 |
| `perplexity_on_dev` | dev 困惑度 < 阈值（唐诗 <50） | M4 |

## 3. 常见坑（写代码时已规避，报错时可对照）

| 现象 | 原因 / 检查点 |
|---|---|
| tokenizer roundtrip 失败 | merge 顺序错 / decode 跨 UTF-8 边界。本实现按字节做，decode 时先整体展开成字节串再 utf-8，天然可还原 |
| `kv_cache_equivalence` 不通过 | **增量解码位置没接续**：新 token 的 RoPE 角度要用 offset=历史长度。本实现由 `cache[0].shape[2]` 取 offset |
| KV cache 拼接维度错 | cache 应在序列维（dim=2）append；本实现 `torch.cat(..., dim=2)` |
| 长序列 shape 报错 / PPL 失真 | 上下文超过训练长度；自检按 `block_size` 切窗喂 block+1 即可，RoPE 是动态生成的不设上限表 |
| loss 偶发 spike | 加了 grad clipping；若仍不稳调小 lr |
| head_dim 奇数 | RoPE half-split 需要偶数，`CausalSelfAttention` 里有断言 |
